# Temperature Converter

## OIBSIP Web Development & Designing Internship

### Level 1 - Task 3

This project is a temperature converter website created as part of
the OIBSIP Web Development & Designing Internship.

## Project Overview

The Temperature Converter allows users to enter a temperature value,
select the original temperature unit, select the unit they want to
convert to, and view the converted result.

## Features

- Convert Celsius to Fahrenheit
- Convert Celsius to Kelvin
- Convert Fahrenheit to Celsius
- Convert Fahrenheit to Kelvin
- Convert Kelvin to Celsius
- Convert Kelvin to Fahrenheit
- Clear button to reset the converter
- Input validation
- Absolute zero validation
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Live Server

## Temperature Units

The converter supports:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

## How It Works

1. Enter a temperature value.
2. Select the original temperature unit.
3. Select the unit you want to convert to.
4. Click the Convert button.
5. The converted temperature will be displayed.
6. Click Clear to reset the converter.

## Example

If the user enters:

Temperature: 100

From: Celsius

To: Fahrenheit

The result will be:

212.00° F

## Input Validation

The application checks whether the user has entered a valid
temperature value.

It also prevents temperatures below absolute zero from being
converted.

## Responsive Design

The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile devices

CSS media queries are used to make the converter responsive.
