# Personal Portfolio Website

## OIBSIP Web Development & Designing Internship

### Level 1 - Task 2

This project is a personal portfolio website created as part of the
OIBSIP Web Development & Designing Internship.

## Project Overview

The purpose of this project is to create a professional personal
portfolio that presents a developer's introduction, skills, projects,
and contact information.

## Features

- Responsive navigation bar
- Hero/Profile section
- About Me section
- Skills section
- Projects section
- Contact section
- Smooth scrolling navigation
- Responsive design
- Hover effects
- Mobile-friendly layout
- Consistent branding

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Live Server

## Portfolio Sections

### Home

Introduces Alex Morgan as a front-end web developer and provides
buttons to view projects and contact information.

### About Me

Provides information about the developer's interests, learning journey,
and career goal.

### Skills

The portfolio includes the following skills:

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Git & GitHub
- VS Code

### Projects

The portfolio contains three example projects:

1. Landing Page
2. Temperature Converter

### Contact

Contact information is provided through:

- Email
- GitHub
- LinkedIn

## Responsive Design

The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile devices

CSS media queries are used to adjust the layout for smaller screens.

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click inside the file.
4. Select "Open with Live Server".
5. The website will open in your browser.
